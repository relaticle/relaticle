> **Superseded during implementation.** This plan is the pre-implementation design; several tasks changed scope while being built (docs `<lastmod>` deferred to W2, the D8 alt-text defect retracted, the MCP guard middleware, and other details below). `docs/superpowers/specs/2026-08-11-seo-geo-strategy-design.md` records both changes and is the authoritative post-implementation reference — read it first if this plan and the spec disagree.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the two code PRs of the SEO/GEO program spec (`docs/superpowers/specs/2026-08-11-seo-geo-strategy-design.md`): W0 site hygiene, then W1 blog-authoring MCP endpoint + SystemAdministrator API tokens.

**Architecture:** W0 is a set of independent fixes to routes, config, sitemap generation, and views. W1 flips on ink v2.3.1's built-in blog MCP server and adds the three host-side integrations it needs (explicit policy registration, author resolution, token issuance UI) — the FilaForms-proven pattern.

**Tech Stack:** Laravel 12 / PHP 8.4, Filament (sysadmin panel), relaticle/ink v2.3.1, laravel/mcp ^0.9.1, laravel/sanctum, spatie/laravel-markdown, spatie/laravel-markdown-response, spatie/laravel-sitemap, Pest 5.

<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

final class DenySearchIndexing
{
    public function handle(Request $request, Closure $next): Response
    {

        $response->headers->set('X-Robots-Tag', 'noindex, nofollow');

        return $response;
    }
}

### Task 4: Markdown heading pipeline — kill the literal `#` and mangled ids (D4)

**Files:**
- Modify: `config/markdown.php`
- Modify: `packages/Documentation/src/Data/DocumentData.php` (TOC extraction)
- Test: `tests/Feature/Documentation/DocumentationHeadingsTest.php` (create; check first whether an existing `tests/Feature/Documentation*` file covers `/docs` rendering — if so, extend it instead)

**Interfaces:**
- Consumes: `MarkdownRenderer` (spatie), `DocumentData::fromType()`.
- Produces: heading HTML shape all later content work relies on: `<h2><a id="slug" href="#slug" class="heading-permalink" title="Permalink" aria-hidden="true"></a>Heading text</h2>` — anchors on h2-h6 only, empty symbol, no outer heading id.

Verified root cause (reproduced via tinker): `config/markdown.php` runs BOTH spatie's `add_anchors_to_headings` and an explicit `commonmark_options.heading_permalink` block (symbol `#`, `min_heading_level: 1`); the second pass slugifies the first pass's anchor markup into the heading id, and the `#` symbol renders as visible text. ink's `Post::tableOfContents()` DOM-parses the *injected permalink anchor* for fragments, so anchors must stay — only the symbol, the h1 anchor, and the double-processing go.

- [ ] **Step 1: Write the failing test**

```php

    expect(trim(strip_tags($h1[1])))->toBe('MCP Server')
        ->and($html)->not->toMatch('/<h1[^>]*id="a-id/')
        ->and($html)->not->toContain('>#</a>');
});

it('still extracts a table of contents from h2 permalink anchors', function (): void {
    $document = DocumentData::fromType('mcp');

    expect($document->tableOfContents)->not->toBeEmpty();
});
```

// MCP callers authenticate as sysadmin accounts, but posts belong to User
