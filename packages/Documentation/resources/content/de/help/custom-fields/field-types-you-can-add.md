Wenn Sie ein Attribut hinzufügen, wählen Sie seinen Typ. Der Typ bestimmt, wie
das Attribut eingegeben, angezeigt, gefiltert und geprüft wird. Wählen Sie mit
Bedacht, denn der Typ eines Attributs ist nach dem Erstellen gesperrt.

## Text und Zahlen

| Typ | Geeignet für |
|-----|--------------|
| Text | Kurze einzeilige Werte: eine Position, eine Region |
| Mehrzeiliger Text | Ein paar Sätze ohne Formatierung |
| Rich-Text-Editor | Formatierte Inhalte: Überschriften, Listen, Tabellen, Bilder. Tippen Sie /, um einen Block einzufügen |
| Zahl | Reine Zahlenwerte: Mitarbeiterzahl, ein Score |
| Währung | Geld: Beträge von Verkaufschancen, Vertragswerte |

## Kontakt und Web

| Typ | Geeignet für |
|-----|--------------|
| E-Mail | Geprüfte E-Mail-Adressen |
| Telefonnummer | Telefonnummern |
| Link | URLs: Websites, LinkedIn-Profile |

## Datumsangaben

| Typ | Geeignet für |
|-----|--------------|
| Datum | Ein Tag: Abschlussdatum, Verlängerungsdatum |
| Datum und Uhrzeit | Ein Zeitpunkt: ein Demo-Gespräch, eine Frist |

## Auswahl

| Typ | Geeignet für |
|-----|--------------|
| Auswahl | Ein Wert aus einer Liste: Phase, Stufe, Branche |
| Mehrfachauswahl | Mehrere Werte aus einer Liste |
| Optionsfeld | Ein Wert, alle Optionen auf einmal sichtbar |
| Checkbox | Ein einzelnes Ja/Nein-Häkchen |
| Checkbox-Liste | Mehrere Häkchen aus einer festen Liste |
| Schalter | Ein Ein/Aus-Schalter, z. B. „Ist das ein ICP-Unternehmen?“ |
| Umschaltflächen | Ein Wert, als Schaltflächen dargestellt |
| Tag-Eingabe | Freie Tags, eingetippt und wiederverwendbar |

Auswahl-Attribute bringen ihre eigenen Optionslisten mit. Siehe
[Optionen eines Auswahl-Attributs bearbeiten](/de/help/custom-fields/edit-the-options-in-a-select-field).

## Sonstige Typen

| Typ | Geeignet für |
|-----|--------------|
| Farbwähler | Ein Farbwert |
| Eintrag | Eine Verknüpfung mit einem anderen Eintrag: ein Unternehmen mit einem Unternehmen, eine Person mit einer Verkaufschance verbinden |

E-Mail, Link und einige andere Typen können pro Eintrag auch **mehrere Werte**
halten, wenn Sie das in den Einstellungen des Attributs aktivieren. So
speichert das eingebaute Attribut „E-Mail-Adressen“ mehrere Adressen für eine
Person.
