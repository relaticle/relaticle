Ihre persönlichen Einstellungen finden Sie unter Ihrem Avatar oben rechts. Wählen Sie
**Einstellungen**. Sie gehören nur Ihnen und begleiten Sie in jeden Arbeitsbereich, in
dem Sie Mitglied sind.

## Profilinformationen

Laden Sie ein Profilfoto hoch (beschneiden Sie es im Editor, oder mit **Foto
entfernen** kehren Sie zu den Initialen zurück) und ändern Sie Ihren Namen oder Ihre
E-Mail-Adresse. Bei einer Änderung der E-Mail-Adresse geht ein Bestätigungslink an die
neue Adresse. Die Änderung gilt, sobald Sie sie bestätigen.

Die **Zeitzone** bestimmt, wie jedes Datum und jede Uhrzeit in der App für Sie
erscheint. Andere Mitglieder behalten ihre eigene Einstellung, sodass jeder von Ihnen
denselben Eintrag in der eigenen Ortszeit sieht.

## Passwort

Öffnen Sie den Tab **Sicherheit** für Ihr Passwort, Ihre Passkeys, die
Zwei-Faktor-Authentifizierung und Ihre Browsersitzungen.

Geben Sie Ihr neues Passwort ein, bestätigen Sie es und wählen Sie dann
**Speichern**. Bestätigen Sie Ihre Identität mit einem Passkey, einem Passwort oder
einem verknüpften Anbieter. Konten ohne Passwort zeigen im selben Bereich
**Passwort festlegen**.

## Passkeys

Ein Passkey meldet Sie mit Face ID, Touch ID oder der Bildschirmsperre Ihres Geräts
an, statt mit einem Passwort. **Passkeys** listet die Passkeys Ihres Kontos auf, wann
jeder hinzugefügt wurde und wann er zuletzt verwendet wurde.

**Passkey hinzufügen** bestätigt zunächst, dass Sie es sind, und übergibt dann an Ihren
Browser oder Passwortmanager, der den Schlüssel erstellt. Relaticle benennt ihn nach
dem Authenticator, den es erkennt. Möchten Sie ihn lieber nach dem Gerät benennen, nutzen Sie
**Umbenennen**. **Entfernen** nimmt einen Passkey aus Ihrem Konto. Dieses Gerät kann Sie
dann nicht mehr anmelden. Relaticle behält Ihre letzte Anmeldemethode. Fügen Sie einen
weiteren Passkey hinzu oder legen Sie ein Passwort fest, bevor Sie ihn entfernen.

Bei der nächsten Anmeldung geben Sie Ihre E-Mail-Adresse ein, und die Passkey-Abfrage
erscheint von selbst. Auf einem Gerät, das bereits einen enthält, bietet das Feld für
die E-Mail-Adresse ihn an, sobald Sie hineinklicken.

## Ihre Identität bestätigen

Sensible Änderungen verlangen, dass Sie Ihre Identität mit einem Passkey oder
Passwort bestätigen. Ein Passkey bestätigt Ihre Identität mit Fingerabdruck, Gesicht
oder Geräte-PIN. Verwenden Sie ein Passwort und haben die Zwei-Faktor-Authentifizierung
aktiviert, geben Sie zusätzlich einen Authenticator-Code ein.

Melden Sie sich nur mit Google oder Microsoft an, bestätigen Sie über diesen
Anbieter. Zusätzlich geben Sie einen Authenticator-Code ein, wenn die
Zwei-Faktor-Authentifizierung aktiviert ist.

## Zwei-Faktor-Authentifizierung

Wählen Sie unter **Sicherheit** bei **Zwei-Faktor-Authentifizierung** die Option
**Aktivieren**. Bestätigen Sie Ihre Identität, scannen Sie den Code mit Ihrer
Authenticator-App und geben Sie deren sechsstelligen Code ein. Speichern Sie Ihre
Wiederherstellungscodes, bevor Sie den Einrichtungsdialog schließen.

Eine Anmeldung mit einem Passkey erfüllt die Zwei-Faktor-Authentifizierung ohne
zusätzlichen Authenticator-Code. Bei einer Anmeldung mit Passwort, Google oder
Microsoft ist weiterhin ein Authenticator-Code erforderlich. Verwenden Sie einen
Wiederherstellungscode, wenn Sie nicht auf Ihre Authenticator-App zugreifen können.

## Browsersitzungen

**Browsersitzungen** listet auf, wo Sie überall angemeldet sind: Gerät, Browser und
letzte Aktivität. **Andere Browsersitzungen abmelden** meldet jedes Gerät ab, außer dem,
das Sie gerade verwenden. Tun Sie das immer, wenn Sie einen gemeinsam genutzten
Rechner verwendet haben.

Auch wenn Sie Ihr Passwort ändern oder zurücksetzen, werden Ihre anderen Geräte
abgemeldet.

Bei einer selbst gehosteten Installation, die Sitzungen in Redis speichert, funktioniert
**Andere Browsersitzungen abmelden** anders. Ein Gerät wird erst abgemeldet, nachdem es
zwei Stunden lang inaktiv war (die standardmäßige Sitzungsdauer). Ein Gerät mit
geöffnetem Relaticle bleibt angemeldet. Ändern Sie Ihr Passwort, um es sofort
abzumelden.

## Benachrichtigungen

Die Seite **Benachrichtigungen** neben Ihren Profileinstellungen steuert die
Benachrichtigungen zu Aufgabenzuweisungen und die tägliche Zusammenfassung, beschrieben
unter [Mit Aufgaben arbeiten](/de/help/tasks-and-notes/work-with-tasks).

## Ihr Konto löschen

Um die Löschung Ihres Kontos zu beantragen, schreiben Sie an
[privacy@relaticle.com](mailto:privacy@relaticle.com) oder [kontaktieren Sie uns](/de/contact).
Bei einer selbst gehosteten Installation wenden Sie sich an die Person, die sie
verwaltet.

Wenn **Konto löschen** unten im **Profil** verfügbar ist, können Sie die Löschung dort
planen. Geben Sie die E-Mail-Adresse Ihres Kontos ein und bestätigen Sie Ihre
Identität. Die Löschung wird **30 Tage später** angesetzt. Melden Sie sich in diesen 30
Tagen an und wählen Sie **Mein Konto behalten**, um sie abzubrechen. Nach der Frist
werden Ihr Konto und Ihre personenbezogenen Daten endgültig entfernt. Einträge in
gemeinsamen Arbeitsbereichen bleiben bestehen.

Bevor Sie die Löschung planen, entfernen Sie andere Mitglieder aus Arbeitsbereichen,
die Ihnen gehören, oder löschen Sie diese Arbeitsbereiche.
