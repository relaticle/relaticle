Eine Verkaufschance ist ein laufendes Verkaufsprojekt. Sie wandert als Karte auf dem
Board der Verkaufschancen durch Ihre Pipeline. Legen Sie sie an und ziehen Sie
ihre Karte in die nächste Spalte, sobald sie voranschreitet, bis hin
zu Gewonnen oder Verloren.

1. Klicken Sie in der Seitenleiste auf **Verkaufschancen**.
2. Klicken Sie auf **Erstellen**.
3. Geben Sie den Namen der Verkaufschance in **Name** ein. Das ist das einzige
   Pflichtfeld.
4. Wählen Sie ein **Unternehmen** und einen **Ansprechpartner** aus, wenn die
   Verkaufschance mit einem verbunden ist.
5. Füllen Sie **Betrag**, **Abschlussdatum** oder **Phase** aus, wenn Sie sie
   kennen. Sie können sie auch später festlegen.
6. Klicken Sie auf **Erstellen**.

## Ihre Pipeline ansehen

Öffnen Sie **Verkaufschancen**. Die Seite öffnet sich mit **Pipeline**, dem Board.
Falls sie mit einer anderen Ansicht startet, öffnen Sie oben links das
Ansichtsmenü und wählen **Pipeline**. Standardmäßig erscheint jede Phase
(Akquise, Qualifizierung, Bedarfsanalyse, Nutzenversprechen, Entscheider
identifizieren, Wahrnehmungsanalyse, Angebot/Preisangebot, Verhandlung/Prüfung,
Gewonnen und Verloren) als Spalte, und darunter steht jede Verkaufschance als
Karte. Öffnen Sie **Ansichtseinstellungen** und erstellen Sie mit **Gruppiert
nach** die Spalten aus einem anderen Attribut mit Einfachauswahl.

![Das Board der Verkaufschancen mit Abschlüssen, gruppiert in die Spalten Prospecting, Qualification, Needs Analysis und Value Proposition](/help-assets/getting-started/track-a-deal-through-the-pipeline-1.png)

## Die Phasen in eigene Reihenfolge bringen

Ziehen Sie eine Spaltenüberschrift nach links oder rechts, um diese Phase zu
verschieben. Sie können auch oben am Board auf **Ansichtseinstellungen** klicken
und die Phasen unter **Sichtbare Spalten** ziehen. Das Menü einer Phase bietet
dort ebenfalls **Nach oben** und **Nach unten**. Schalten Sie dort eine Phase
aus, um ihre Spalte auszublenden. Schalten Sie **Ohne Phase** ein, um eine erste
Spalte für Verkaufschancen ohne Phase hinzuzufügen. Ziehen Sie eine
Verkaufschance dorthin, wird ihre Phase geleert. Die Reihenfolge wird nur für Sie
gespeichert, andere Mitglieder behalten ihre eigene. Sie ändert nie die
Reihenfolge in den Einstellungen des Attributs **Phase**, die für alle die
Ausgangsreihenfolge bleibt. Eine später hinzugefügte Phase reiht sich am Ende
Ihrer Reihenfolge ein.

## Eine Verkaufschance voranbringen

Ziehen Sie die Karte einer Verkaufschance aus ihrer aktuellen Spalte in die
Spalte der nächsten Phase. Die Änderung wird gespeichert, sobald Sie die Karte
loslassen, ohne dass Sie den Eintrag öffnen müssen. Ist eine **Sortierung**
gesetzt, können Sie eine Karte weiterhin in eine andere Spalte ziehen, ihre
Reihenfolge aber nicht von Hand ändern.

Die Phase lässt sich auch im Eintrag selbst ändern: Öffnen Sie ihn, klicken Sie
auf **Bearbeiten**, wählen Sie eine neue **Phase** und klicken Sie auf
**Änderungen speichern**.

## Wenn die Phasennamen nicht zu Ihrem Vertriebsprozess passen, bearbeiten Sie sie

Phase ist ein Attribut wie jedes andere. Klicken Sie oben in der Seitenleiste auf
den Namen Ihres Arbeitsbereichs, klicken Sie auf **Benutzerdefinierte
Attribute**, wählen Sie den Tab **Verkaufschancen** und öffnen Sie **Phase** über
das Menü **Aktionen**. Sie können Phasen umbenennen, neu einfärben, umsortieren
oder neue hinzufügen. Wie Attributeinstellungen funktionieren, steht unter
[Benutzerdefinierte Attribute verwenden](/de/help/getting-started/use-custom-fields).
