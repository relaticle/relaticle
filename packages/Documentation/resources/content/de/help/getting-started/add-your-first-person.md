Ein Personeneintrag steht für jeden, mit dem Sie in Kontakt sind: jemanden bei
einem Unternehmen, an das Sie verkaufen, einen Bewerber oder jede andere
Person, die Sie festhalten möchten. Zum Anlegen brauchen Sie nur einen Namen.

1. Klicken Sie in der Seitenleiste auf **Personen**.
2. Klicken Sie oben rechts auf **Erstellen**.
3. Geben Sie den Namen in **Name** ein. Das ist das einzige Pflichtfeld.
4. Wählen Sie ein **Unternehmen** aus, mit dem die Person verknüpft werden soll,
   oder klicken Sie daneben auf **+**, um das Unternehmen direkt anzulegen.
5. Füllen Sie **E-Mail-Adressen**, **Telefonnummer**, **Position** oder
   **LinkedIn** aus, wenn Sie die Angaben haben. Sie können sie auch später
   ergänzen.
6. Klicken Sie auf **Erstellen**.

Die Person erscheint sofort in Ihrer Liste **Personen** und, falls Sie ein
Unternehmen zugewiesen haben, auf dem Tab **Personen** dieses Unternehmens.

## Wenn Sie die erwarteten Felder nicht sehen

Ihr Team hat möglicherweise Felder für Personen hinzugefügt oder entfernt.
Fragen Sie einen Administrator des Arbeitsbereichs. Attribute, die auf der Seite
**Benutzerdefinierte Attribute** eingerichtet sind, erscheinen automatisch im
Formular zum Erstellen.
