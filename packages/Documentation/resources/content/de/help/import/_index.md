---
title: Daten importieren
description: Übernehmen Sie bestehende Daten aus CSV-Dateien in Relaticle und beheben Sie alles, was der Import-Assistent markiert.
order: 2
---

Alles rund um das Übernehmen von Daten in Relaticle: eine CSV-Datei
vorbereiten, die der Import-Assistent auf Anhieb akzeptiert, Zeilen mit bereits
vorhandenen Einträgen verknüpfen und die Werte klären, die er unterwegs
markiert.

Wenn Sie noch nie einen Import durchgeführt haben, beginnen Sie mit der
Schritt-für-Schritt-Anleitung:
[Bestehende Daten importieren](/de/help/getting-started/import-your-existing-data).

Wie Sie neue Leads übernehmen, sobald sie eintreffen, steht unter
[Leads aus einem Webformular erfassen](/de/help/import/capture-leads-from-a-web-form).
