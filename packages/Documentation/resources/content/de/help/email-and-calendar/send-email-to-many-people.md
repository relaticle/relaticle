Beim Massenversand schreiben Sie eine Nachricht, und sie wird als separate E-Mail an
jeden Empfänger gesendet. Niemand sieht die anderen Empfänger, und Platzhalter
füllen die Angaben der jeweiligen Person ein.

## An eine Auswahl senden

1. Öffnen Sie die Liste **Personen** oder **Unternehmen**.
2. Markieren Sie die Einträge, die Sie erreichen möchten.
3. Klicken Sie in der Leiste, die unten in der Liste erscheint, auf **E-Mail senden**.
4. Der Editor öffnet sich als **Neue Massen-E-Mail** mit den aufgelisteten
   Empfängern. Mit **Empfänger hinzufügen** fügen Sie weitere hinzu.
5. Schreiben Sie den Betreff und die Nachricht. **Variable einfügen** fügt einen
   Platzhalter wie den vollständigen Namen oder das Unternehmen ein.
6. Klicken Sie auf **E-Mails senden**. Die Schaltfläche zeigt, wie viele E-Mails
   rausgehen.

Ausgewählte Einträge ohne E-Mail-Adresse werden übersprungen, und Relaticle teilt
Ihnen mit, wie viele es waren.

Sie können auch mit jeder neuen E-Mail beginnen. Aktivieren Sie im Editor
**Massenversand** und fügen Sie dort Empfänger hinzu.

## Eine Nachricht mit einer Vorlage wiederverwenden

Schreiben Sie die Nachricht einmal, und klicken Sie dann im Editor auf **Vorlage
verwenden** und **Als Vorlage speichern**. Aktivieren Sie **Mit Arbeitsbereich teilen**,
damit alle sie nutzen können.

Vorlagen stehen unter **E-Mails** auf dem Tab **Vorlagen**. Mit **Neue Vorlage**
schreiben Sie eine von Grund auf.

## Wie schnell eine Massen-E-Mail rausgeht

Jedes verbundene Postfach hat ein **Sendelimit pro Stunde** und ein **Sendelimit pro
Tag**. Eine Massen-E-Mail kommt in Ihren Postausgang und geht so schnell raus, wie
diese Limits es zulassen. Ein großer Versand kann daher Stunden dauern.

- Den Fortschritt sehen Sie auf der Seite **E-Mails** unter **Postausgang**.
- Was noch nicht gesendet wurde, brechen Sie mit **Ausgewählte abbrechen** ab.
- Die Limits ändern Sie in den Einstellungen des Postfachs unter **Allgemein**.
  Klicken Sie dazu unter **Einstellungen des Arbeitsbereichs** und **E-Mail und
  Kalender** auf das Postfach. Lassen Sie ein Limit leer, gilt der Standardwert.

## Wenn die Meldung „Keine gültigen Empfänger“ erscheint

Keine der ausgewählten Personen hat eine E-Mail-Adresse. Tragen Sie bei ihnen im Feld
**E-Mail-Adressen** eine Adresse ein und wählen Sie sie erneut aus.
