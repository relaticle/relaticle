Le sélecteur de modèle se trouve dans la zone de message. Cliquez dessus pour
voir quels modèles d'IA votre espace de travail peut utiliser. **Auto** est le
choix par défaut et sélectionne un modèle adapté pour vous. Vous n'avez besoin
de ce menu que si vous voulez arbitrer vous-même entre vitesse et profondeur.

![Le sélecteur de modèle ouvert au-dessus de la zone de message, listant Auto, des modèles Claude et GPT ainsi que des modèles auto-hébergés](/help-assets/ai-assistant/choose-an-ai-model-1.png)

## Ce que contient la liste

Les modèles affichés dépendent de votre offre et, pour les installations
auto-hébergées, de ce que l'opérateur a configuré. Sur Relaticle Cloud :

| Modèle | Disponibilité | Multiplicateur de crédits |
|-------|--------------|-------------------|
| Auto | Tout le monde | Dépend du modèle choisi |
| Claude Sonnet | Tout le monde | 1x |
| Claude Opus | Pro | 3x |
| Modèles de classe GPT-5 | Pro | 1,5x |

Les modèles marqués d'un badge ambre **Pro** exigent un espace de travail Pro.
Pendant l'essai de 14 jours, ils se débloquent dès que l'espace de travail
contient un enregistrement qui lui est propre. D'ici là, le sélecteur propose
les modèles accessibles à tous. Le multiplicateur fait varier le coût d'un
message en crédits. Voir
[Crédits d'IA et limites de débit](/fr/help/ai-assistant/ai-credits-and-limits).

Les espaces de travail auto-hébergés peuvent aussi orienter l'assistant vers
leurs propres modèles (Ollama ou tout point d'accès compatible OpenAI). Ceux-ci
apparaissent dans le même sélecteur une fois configurés.

## Comment le choix se comporte

Votre sélection est mémorisée dans le navigateur où vous l'avez faite et
s'applique aux messages que vous envoyez à partir de là. C'est un choix par
personne : vos collègues choisissent le leur. Revenir à **Auto** est toujours
sans risque.
