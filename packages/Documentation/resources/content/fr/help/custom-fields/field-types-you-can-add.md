Quand vous ajoutez un attribut, vous choisissez son type, et le type décide de
la façon dont l'attribut est saisi, affiché, filtré et validé. Choisissez avec
soin, car le type d'un attribut est verrouillé une fois l'attribut créé.

## Texte et nombres

| Type | Idéal pour |
|------|----------|
| Texte | Valeurs courtes sur une ligne : un intitulé de poste, une région |
| Zone de texte | Quelques phrases sans mise en forme |
| Éditeur de texte enrichi | Contenu mis en forme : titres, listes, tableaux, images. Tapez / pour insérer un bloc |
| Nombre | Valeurs numériques simples : effectif, un score |
| Devise | Argent : montants d'opportunités, valeurs de contrats |

## Contact et web

| Type | Idéal pour |
|------|----------|
| E-mail | Adresses e-mail validées |
| Numéro de téléphone | Numéros de téléphone |
| Lien | URL : sites web, profils LinkedIn |

## Dates

| Type | Idéal pour |
|------|----------|
| Date | Un jour : date de clôture, date de renouvellement |
| Date et heure | Un moment : un appel de démo, une échéance |

## Choix

| Type | Idéal pour |
|------|----------|
| Liste déroulante | Une valeur dans une liste : étape, palier, secteur |
| Sélection multiple | Plusieurs valeurs dans une liste |
| Boutons radio | Une valeur, toutes les options visibles d'un coup |
| Case à cocher | Une simple coche oui/non |
| Liste de cases à cocher | Plusieurs coches dans une liste fixe |
| Interrupteur | Un interrupteur activé/désactivé, par exemple « est-ce une entreprise du profil client idéal ? » |
| Boutons à bascule | Une valeur, affichée sous forme de boutons |
| Saisie de tags | Tags libres, saisis et réutilisables |

Les attributs de choix portent leurs propres listes d'options. Voir
[Modifier les options d'un attribut de sélection](/fr/help/custom-fields/edit-the-options-in-a-select-field).

## Spécial

| Type | Idéal pour |
|------|----------|
| Sélecteur de couleur | Une valeur de couleur |
| Enregistrement | Un lien vers un autre enregistrement : relier une entreprise à une entreprise, une personne à une opportunité |

E-mail, Lien et quelques autres types peuvent aussi contenir **plusieurs
valeurs** par enregistrement quand vous l'activez dans les paramètres de
l'attribut. C'est ainsi que l'attribut E-mails intégré stocke plusieurs adresses
pour une même personne.
