Les attributs personnalisés capturent tout ce que Relaticle ne suit pas d'office,
comme une source de prospect, une date de renouvellement ou une priorité
interne, sur les entreprises, personnes, opportunités, notes ou tâches. Ajoutez-en
un depuis la page Attributs personnalisés et il apparaît tout de suite dans les
formulaires de création et de modification de ce type d'enregistrement, sans
autre réglage.

1. Cliquez sur le nom de votre espace de travail en haut de la barre latérale,
   puis sur **Attributs personnalisés**.
2. Sélectionnez l'onglet du type d'enregistrement : **Entreprises**,
   **Personnes**, **Opportunités**, **Notes** ou **Tâches**.
3. Cliquez sur **Ajouter un attribut**.
4. Choisissez un **Type** : Texte, Nombre, Devise, Date, Liste déroulante,
   Sélection multiple, Case à cocher, Lien, Saisie de tags, et d'autres.
5. Saisissez un nom dans **Nom**.
6. Pour les attributs de type Liste déroulante, cliquez sur **Ajouter une
   option** pour chaque choix.
7. Cliquez sur **Valider**.

L'attribut apparaît immédiatement partout où ce type d'enregistrement est créé
ou modifié.

![Le formulaire de création d'une opportunité avec un nouvel attribut Deal Source juste sous Étape](/help-assets/getting-started/use-custom-fields-2.png)

## Réglages d'un attribut

Chaque attribut a des interrupteurs **Visible dans la liste**, **Visible dans
la vue détaillée**, **Masqué par défaut, affichable** et **Chiffré**, plus, pour
les attributs à choix unique, **Activer les couleurs des options** ou **Unique
par type d'enregistrement**. La plupart des attributs peuvent aussi être filtrés
depuis la rangée de filtres au-dessus de la liste du type d'enregistrement.
Consultez
[Tout trouver avec la recherche et les filtres](/fr/help/getting-started/find-anything-with-search-and-filters).

## Si un attribut est marqué Système, vous pouvez le modifier mais pas le supprimer

Des attributs comme Montant, Date de clôture et Étape sur les opportunités, ou
Domaines sur les entreprises, sont fournis avec Relaticle et portent un badge
**Système**. Ouvrez-en un depuis son menu **Actions** pour le renommer, ou pour
réordonner, recolorer ou ajouter ses options. Le menu ne propose simplement pas
**Supprimer**.
