Un enregistrement d'entreprise suit une entreprise à laquelle vous vendez ou avec laquelle
vous travaillez : son nom, qui gère la relation, et les personnes, tâches et
notes qui y sont liées. Un nom suffit pour en créer un. Le reste peut attendre.

1. Cliquez sur **Entreprises** dans la barre latérale.
2. Cliquez sur **Créer** en haut à droite.
3. Saisissez le nom de l'entreprise dans **Nom**. C'est le seul champ
   obligatoire.
4. Sélectionnez un **Responsable** si vous voulez confier l'entreprise à un
   collègue.
5. Renseignez **Domaines**, **LinkedIn**, ou activez **ICP** si vous les
   connaissez déjà. Vous pourrez les ajouter plus tard.
6. Cliquez sur **Créer**.

L'entreprise apparaît tout de suite dans votre liste Entreprises. Ouvrez-la
pour lier les personnes qui y travaillent, consigner une tâche ou laisser une
note. Ces éléments se trouvent dans les onglets **Personnes**, **Tâches** et
**Notes** de l'enregistrement de l'entreprise.

## Si vous ne voyez pas les champs attendus

Votre équipe a peut-être ajouté ou retiré des champs pour les entreprises.
Demandez à un administrateur de l'espace de travail. Les attributs configurés
sur la page **Attributs personnalisés** apparaissent automatiquement dans le
formulaire de création.
