Vous découvrez Relaticle ? Commencez ici pour ajouter vos premiers
enregistrements et faire entrer votre équipe dans l'espace de travail.

Relaticle organise vos données clients en cinq types d'enregistrements liés :

| Type d'enregistrement | Rôle | Exemple |
|--------|---------|---------|
| **Entreprises** | Les organisations avec lesquelles vous travaillez | Acme Corporation |
| **Personnes** | Les individus avec lesquels vous travaillez | John Doe, PDG chez Acme |
| **Opportunités** | Les ventes en cours dans votre pipeline | Contrat entreprise T1 |
| **Tâches** | Les actions à accomplir | Relancer après la proposition |
| **Notes** | Les informations à retenir | Notes d'un appel |

Les personnes appartiennent à des entreprises, les opportunités sont liées à
des entreprises et à des personnes, et les tâches et les notes peuvent être
rattachées à n'importe quel enregistrement.
