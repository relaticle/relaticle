Un enregistrement de personne représente toute personne avec qui vous êtes en contact : quelqu'un
d'une entreprise à laquelle vous vendez, un candidat, ou toute autre personne
que vous voulez suivre. Un nom suffit pour en créer un.

1. Cliquez sur **Personnes** dans la barre latérale.
2. Cliquez sur **Créer** en haut à droite.
3. Saisissez son nom dans **Nom**. C'est le seul champ obligatoire.
4. Sélectionnez une **Entreprise** à laquelle la lier, ou cliquez sur le **+**
   à côté pour créer l'entreprise sur-le-champ.
5. Renseignez **E-mails**, **Numéro de téléphone**, **Poste** ou **LinkedIn**
   si vous les avez. Vous pourrez les ajouter plus tard.
6. Cliquez sur **Créer**.

La personne apparaît tout de suite dans votre liste Personnes, et dans l'onglet
**Personnes** de l'entreprise liée si vous en avez choisi une.

## Si vous ne voyez pas les champs attendus

Votre équipe a peut-être ajouté ou retiré des champs pour les personnes.
Demandez à un administrateur de l'espace de travail. Les attributs configurés
sur la page **Attributs personnalisés** apparaissent automatiquement dans le
formulaire de création.
