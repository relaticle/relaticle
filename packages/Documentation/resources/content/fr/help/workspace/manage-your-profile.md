Vos paramètres personnels se trouvent sous votre avatar, en haut à droite. Choisissez
**Paramètres**. Ils vous appartiennent et vous suivent dans tous les espaces de
travail dont vous faites partie.

## Informations de profil

Importez une photo de profil (recadrez-la dans l'éditeur, ou **Supprimer la photo**
pour revenir aux initiales), et changez votre nom ou votre e-mail. Changer l'e-mail
envoie un lien de vérification à la nouvelle adresse. Le changement s'applique une
fois que vous l'avez confirmé.

**Fuseau horaire** détermine comment chaque date et chaque heure de l'application
s'affichent pour vous. Les autres membres gardent leur propre réglage : chacun voit
donc le même enregistrement à sa propre heure locale.

## Mot de passe

Ouvrez l'onglet **Sécurité** pour votre mot de passe, vos clés d'accès,
l'authentification à deux facteurs et vos sessions du navigateur.

Saisissez et confirmez votre nouveau mot de passe, puis choisissez **Enregistrer**.
Confirmez votre identité avec une clé d'accès, un mot de passe ou un fournisseur lié.
Les comptes sans mot de passe affichent **Définir un mot de passe** dans la même
section.

## Clés d'accès

Une clé d'accès vous connecte avec Face ID, Touch ID ou le verrouillage d'écran de
votre appareil, à la place d'un mot de passe. **Clés d'accès** liste celles de votre
compte, la date d'ajout de chacune et la date de sa dernière utilisation.

**Ajouter une clé d'accès** confirme que c'est bien vous, puis passe la main à votre
navigateur ou à votre gestionnaire de mots de passe pour créer la clé. Relaticle la
nomme d'après l'authentificateur qu'il reconnaît. Utilisez **Renommer** si vous
préférez l'étiqueter par appareil. **Supprimer** retire une clé d'accès de votre
compte : cet appareil ne peut plus vous connecter. Relaticle conserve votre dernière
méthode de connexion. Ajoutez une autre clé d'accès ou définissez un mot de passe
avant de la supprimer.

À votre prochaine connexion, saisissez votre e-mail et l'invite de clé d'accès
apparaît d'elle-même. Sur un appareil qui en détient déjà une, le champ e-mail la
propose dès que vous cliquez dedans.

## Confirmer que c'est vous

Les modifications sensibles vous demandent de confirmer votre identité avec une clé
d'accès ou un mot de passe. Une clé d'accès confirme votre identité avec votre
empreinte, votre visage ou le code PIN de l'appareil. Si vous utilisez un mot de passe
et que l'authentification à deux facteurs est activée, saisissez aussi un code
d'authentification.

Si vous vous connectez uniquement avec Google ou Microsoft, confirmez via ce
fournisseur. Vous saisissez aussi un code d'authentification si l'authentification à
deux facteurs est activée.

## Authentification à deux facteurs

Dans **Sécurité**, choisissez **Activer** sous **Authentification à deux facteurs**.
Confirmez votre identité, scannez le code avec votre application d'authentification et
saisissez son code à six chiffres. Enregistrez vos codes de récupération avant de
fermer la fenêtre de configuration.

Se connecter avec une clé d'accès satisfait l'authentification à deux facteurs sans
code d'authentification supplémentaire. Se connecter avec un mot de passe, Google ou
Microsoft exige toujours un code d'authentification. Utilisez un code de récupération
si vous ne pouvez pas accéder à votre application d'authentification.

## Sessions du navigateur

**Sessions du navigateur** liste tous les endroits où vous êtes connecté : appareil,
navigateur et dernière activité. **Déconnecter les autres sessions du navigateur**
déconnecte tous les appareils sauf celui que vous utilisez. Faites-le chaque fois que
vous avez utilisé une machine partagée.

Changer ou réinitialiser votre mot de passe déconnecte aussi vos autres appareils.

Sur une installation auto-hébergée qui garde les sessions dans Redis, **Déconnecter
les autres sessions du navigateur** fonctionne différemment. Un appareil n'est
déconnecté qu'après deux heures d'inactivité, la durée de session par défaut. Un
appareil sur lequel Relaticle reste ouvert reste connecté. Changez votre mot de passe
pour le déconnecter tout de suite.

## Notifications

La page **Notifications**, à côté de vos paramètres de profil, contrôle les alertes
d'assignation de tâches et le résumé quotidien, décrits dans
[Travailler avec les tâches](/fr/help/tasks-and-notes/work-with-tasks).

## Supprimer votre compte

Pour demander la suppression de votre compte, écrivez à [privacy@relaticle.com](mailto:privacy@relaticle.com) ou [contactez-nous](/fr/contact).
Pour une installation auto-hébergée, contactez la personne qui l'administre.

Si **Supprimer le compte** est disponible en bas de **Profil**, vous pouvez y programmer
la suppression. Saisissez l'e-mail de votre compte et confirmez votre identité. La
suppression est programmée **dans 30 jours**. Connectez-vous pendant ces 30 jours et
choisissez **Conserver mon compte** pour l'annuler. Après le délai de grâce, votre
compte et vos données personnelles sont supprimés définitivement. Les enregistrements
des espaces de travail partagés restent.

Avant de programmer la suppression, retirez les autres membres des espaces de travail
dont vous êtes propriétaire, ou supprimez ces espaces de travail.
