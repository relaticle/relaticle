The choices inside every select-style field are yours to edit — and that
includes the two selects Relaticle ships with strong opinions about: the
opportunity **Stage** field (your pipeline) and the task **Status** field
(your board columns).

1. Click your workspace name at the top of the sidebar, then **Custom
   Fields** (workspace owners only).
2. Pick the record type's tab — **Opportunities** for stages, **Tasks** for
   statuses.
3. Open the field and edit its **Options**: rename any option in place,
   **Add Option** for new ones, drag to reorder, or remove ones you don't
   use.

![The Stage field's options editor, each pipeline stage with its own colour swatch, name box, drag handle, and remove button](/help-assets/custom-fields/edit-the-options-in-a-select-field-1.png)

The change lands everywhere at once — forms, list filters, and the boards,
whose columns follow the options and their order exactly. Renaming
"Prospecting" to "New lead" relabels the board column; adding a "Contract
sent" option adds a column.

## What happens to existing records

- **Renaming** an option keeps every record pointing at it — records show the
  new name immediately.
- **Removing** an option clears it from records that used it; they'll show an
  empty value until someone picks a new one. Check the board column is empty
  before removing a stage.

## Colours

If the field has **Enable Color Options** on (Stage does by default), each
option gets a colour swatch, used for the badges in lists and on board
cards. Set colours in the same Options editor.
