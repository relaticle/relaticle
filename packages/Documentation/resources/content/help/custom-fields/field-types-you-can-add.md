When you add a field you pick its type, and the type decides how the field is
entered, displayed, filtered, and validated. Choose carefully — a field's
type is locked once it's created.

## Text and numbers

| Type | Best for |
|------|----------|
| Text | Short one-line values — a job title, a region |
| Textarea | A few sentences without formatting |
| Rich Editor | Formatted content — headings, lists, bold |
| Markdown Editor | The same, written as Markdown |
| Number | Plain numerics — headcount, a score |
| Currency | Money — deal amounts, contract values |

## Contact and web

| Type | Best for |
|------|----------|
| Email | Validated email addresses |
| Phone Number | Phone numbers |
| Link | URLs — websites, LinkedIn profiles |

## Dates

| Type | Best for |
|------|----------|
| Date | A day — close date, renewal date |
| Date and Time | A moment — a demo call, a deadline |

## Choices

| Type | Best for |
|------|----------|
| Select | One value from a list — stage, tier, industry |
| Multi Select | Several values from a list |
| Radio | One value, all options visible at once |
| Checkbox | A single yes/no tick |
| Checkbox List | Several ticks from a fixed list |
| Toggle | An on/off switch — "is this an ICP account?" |
| Toggle Buttons | One value, shown as buttons |
| Tags Input | Free-form tags, typed and reusable |

Choice fields carry their own option lists — see
[Edit the options in a select field](/help/custom-fields/edit-the-options-in-a-select-field).

## Special

| Type | Best for |
|------|----------|
| Color Picker | A colour value |
| Record | A link to another record — relate a company to a company, a person to an opportunity |

Email, Link, and a few other types can also hold **multiple values** per
record when you enable it in the field's settings — that's how the built-in
Emails field stores several addresses for one person.
