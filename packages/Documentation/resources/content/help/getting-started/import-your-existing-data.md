Import brings in existing companies, people, or opportunities from a
spreadsheet instead of typing them in one at a time. Upload a CSV, map its
columns to Relaticle fields, review the values, then commit — Relaticle shows
you exactly how many records will be created or updated before anything
changes.

1. Click **Companies**, **People**, or **Opportunities** in the sidebar.
2. Click **Import / Export**, then click **Import companies** (the label
   matches whichever list you're on).
3. Click **Choose a .CSV file**, or drop it onto the upload area — up to
   10,000 rows and 10MB.
4. Click **Continue**.

## Map your columns

Relaticle maps your file's columns to Relaticle fields automatically when the
names are close enough.

![The Map step, with File column values Name, Domain, and LinkedIn auto-mapped to the Name, Domains, and LinkedIn fields](/help-assets/getting-started/import-your-existing-data-1.png)

5. Check each **Map To** field, and fix any that mapped incorrectly.
6. Click **Continue**.

## Review and fix values

Relaticle validates every unique value in each column and groups them under
**All**, **Needs Review**, **Modified**, and **Skipped**. Edit a value inline
to correct it, or skip a row you don't want imported.

7. Click **Continue** once you're happy with the mapped values.
8. Review the counts of records that will be created and updated, click
   **Start Import**, then confirm.

![The Import Complete summary showing 2 created, 0 updated, and 0 failed](/help-assets/getting-started/import-your-existing-data-2.png)

Every past import is listed on the **Import History** page, under your
workspace name — including how many rows were created, updated, skipped, or
failed.

## If a column doesn't map automatically, then set it by hand

Open the dropdown under **Map To** for that column and choose the right field
yourself, or click **Clear mapping** to leave that column out of the import
entirely.

For file formatting rules, matching and updating existing records, and fixes
for values the wizard flags, see the
[Importing data](/help/import) articles.
