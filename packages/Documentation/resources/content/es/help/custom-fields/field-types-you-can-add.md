Al agregar un atributo, usted elige su tipo, y el tipo decide cómo se ingresa, se
muestra, se filtra y se valida el atributo. Elija con cuidado, porque el tipo de
un atributo queda fijo una vez creado.

## Texto y números

| Tipo | Ideal para |
|------|------------|
| Texto | Valores cortos de una línea: un cargo, una región |
| Área de texto | Unas pocas oraciones sin formato |
| Editor de texto enriquecido | Contenido con formato: encabezados, listas, tablas, imágenes. Escriba / para insertar un bloque |
| Número | Valores numéricos simples: cantidad de empleados, una puntuación |
| Moneda | Dinero: montos de oportunidades, valores de contratos |

## Contacto y web

| Tipo | Ideal para |
|------|------------|
| Correo electrónico | Direcciones de correo electrónico validadas |
| Número de teléfono | Números de teléfono |
| Enlace | URL: sitios web, perfiles de LinkedIn |

## Fechas

| Tipo | Ideal para |
|------|------------|
| Fecha | Un día: fecha de cierre, fecha de renovación |
| Fecha y hora | Un momento: una llamada de demostración, un plazo |

## Opciones

| Tipo | Ideal para |
|------|------------|
| Selección | Un valor de una lista: etapa, nivel, sector |
| Selección múltiple | Varios valores de una lista |
| Opciones excluyentes | Un valor, con todas las opciones visibles a la vez |
| Casilla | Una sola marca de sí o no |
| Lista de casillas | Varias marcas de una lista fija |
| Interruptor | Un interruptor de activado y desactivado, por ejemplo "¿es una empresa ICP?" |
| Botones de alternancia | Un valor, mostrado como botones |
| Campo de etiquetas | Etiquetas libres, que se escriben y se reutilizan |

Los atributos de opciones tienen sus propias listas de opciones. Consulte
[Editar las opciones de un atributo de selección](/es/help/custom-fields/edit-the-options-in-a-select-field).

## Especiales

| Tipo | Ideal para |
|------|------------|
| Selector de color | Un valor de color |
| Registro | Un enlace a otro registro: relacionar una empresa con otra empresa, una persona con una oportunidad |

Los atributos de Correo electrónico, Enlace y algunos otros tipos también pueden
guardar **varios valores** por registro cuando lo activa en los ajustes del
atributo. Así es como el atributo integrado Correos electrónicos guarda varias
direcciones para una persona.
